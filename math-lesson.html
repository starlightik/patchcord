Квадратные уравнения

Научимся находить корни уравнения с помощью дискриминанта.

Что такое квадратное уравнение?

Квадратным называется уравнение вида ax2 + bx + c = 0, где a, b и c — числа, а a ≠ 0. Числа a, b и c называют коэффициентами уравнения.

Шаг 1. Найди дискриминант

Дискриминант помогает определить, сколько корней у уравнения.

D = b2 − 4ac

Шаг 2. Определи количество корней

  • Если D > 0, уравнение имеет два корня.
  • Если D = 0, уравнение имеет один корень.
  • Если D < 0, действительных корней нет.

Шаг 3. Вычисли корни

Когда D ≥ 0, подставь коэффициенты в формулу корней:

x = (−b ± √D) / 2a

Знак «±» означает, что при D > 0 нужно выполнить вычисление дважды: сначала со знаком «+», затем со знаком «−».

Разберём пример

Решим уравнение x2 − 5x + 6 = 0.

  1. Определяем коэффициенты: a = 1, b = −5, c = 6.
  2. Находим дискриминант: D = (−5)2 − 4 · 1 · 6 = 25 − 24 = 1.
  3. Так как D > 0, у уравнения два корня.
  4. x1 = (5 + √1) / 2 = 3; x2 = (5 − √1) / 2 = 2.
Ответ: x = 2 или x = 3

Самостоятельная работа

Реши уравнения. Сначала найди дискриминант, затем корни.

  3. x2 + 4x + 4 = 0
  4. 3x2 − 12 = 0
  5. x2 − 2x − 8 = 0
  6. 4x2 − 4x + 1 = 0
